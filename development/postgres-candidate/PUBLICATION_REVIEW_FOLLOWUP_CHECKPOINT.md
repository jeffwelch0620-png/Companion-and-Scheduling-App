Source reference projections exclude revision-only bookkeeping and review timestamps; substantive station definitions/setup, standard versions and staffing changes still invalidate source evidence. It excludes ordinary record revision and checkout profile; release state is projected only for unpublished drafts to preserve draft selection safety. ## Recovery after reload

Before sending publication, the preview stores a tab-scoped marker containing only location, actor membership and receipt ID. Network/5xx uncertainty retains it; success or a definite 4xx clears it. Reload reconstructs a warning for that actor/location: check currently published shifts before reviewing or submitting again. Acknowledgment clears the marker. Other actors/locations do not see it.

The marker is per tab: other tabs/devices receive no warning. Server receipt replay, exact revisions and publication phase/selection checks prevent a repeated request from republishing an already published shift. The marker is not an offline command queue and cannot replay a request by itself. Exact in-page retry retains the original frozen envelope and receipt ID. No automatic replay or new submission is initiated on reload. If browser session storage is unavailable, only the in-page recovery remains; production device policy and durable authorized receipt lookup remain open.
